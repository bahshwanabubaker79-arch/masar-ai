# مسار AI (Masar AI) 🚀
### منصة ويب ذكية للتوجيه المهني وإعداد المقابلات بنظام الوكلاء المتعددين (Multi-Agent AI System)

مشروع عملي تطبيقي لمقرر **هندسة الذكاء الاصطناعي (AI Engineering)**  
إشراف: **د. سهير الحضرمي**

---

## 🌟 فكرة المشروع
منصة ويب ذكية قائمة على سرب من 3 وكلاء أذكياء متخصصين (Autonomous Agents) + وكيل تقييم لحظي لحل مشكلة استبعاد الخريجين في أنظمة الفرز الآلي (ATS) وضعف الاستعداد للمقابلات الشخصية:
1. **الوكيل 1 (فاحص ATS والمحلل):** يحلل السيرة الذاتية مقارنة بالوصف الوظيفي، يستخرج الكلمات المفتاحية الناقصة ويحدد فجوات المهارات، ويصدر عقد تسليم آلي للوكيل 2.
2. **الوكيل 2 (مهندس الصياغة والتحسين):** يستلم تقرير الوكيل 1 ويعيد كتابة الإنجازات الضعيفة وفق صيغة جوجل القياسية (XYZ Formula) مع حقن الكلمات المفتاحية، ويصدر عقد تسليم للوكيل 3.
3. **الوكيل 3 (مدرب المقابلات الذكي):** يصمم أسئلة مقابلة مستهدفة للتحقق من المهارات المضافة وسد الفجوات التي رصدها الوكيل 1.
4. **الوكيل 4 (مقيّم الإجابات التفاعلي):** يقيّم إجابة المستخدم في المقابلة التجريبية وفق أركان منهجية **STAR** الأربعة (الموقف، المهمة، الإجراء، النتيجة) مع إعطاء درجة ونموذج إجابة مثالي.

---

## ✨ المميزات الرئيسية
* **تعاون حقيقي بين الوكلاء (Inter-Agent Handoffs):** مخرجات كل وكيل تصبح مدخلات للوكيل الذي يليه تلقائياً عبر عقود تسليم صريحة.
* **نافذة مسار الوكلاء (Agent Trace Drawer):** تتيح للمستخدم والمشرف الأكاديمي رؤية حمولة البيانات (JSON Payloads) وأزمنة الاستجابة بين كل وكيل وآخر.
* **ثنائية اللغة الكاملة:** تدعم العربية (RTL) والإنجليزية (LTR) مع تبديل فوري.
* **تكامل فائق السرعة مع Groq API:** يعتمد على نموذج `llama-3.3-70b-versatile` فائق السرعة عبر معالجات LPU.
* **نمط تجريبي ذكي (Zero Config Demo):** تعمل المنصة فورياً ببيانات محاكاة عالية الدقة حتى بدون إدخال مفتاح API.

## 🛠️ التشغيل المحلي (Local Development)

```bash
# 1. تثبيت الحزم
npm install

# 2. إنشاء ملف المتغيرات البيئية (اختياري في حال توفر مفتاح Groq)
cp .env.example .env.local

# 3. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

---

## ☁️ خطوات النشر على Vercel (Deployment)

1. ارفع المشروع إلى حسابك على GitHub.
2. توجه إلى موقع [Vercel](https://vercel.com) واضغط **Add New Project** ثم استورد المستودع.
3. في خانة **Environment Variables** أضف:
   * `GROQ_API_KEY`: مفتاح Groq الخاص بك (من [console.groq.com](https://console.groq.com)).
   * `GROQ_MODEL`: `llama-3.3-70b-versatile`.
4. اضغط **Deploy**.
